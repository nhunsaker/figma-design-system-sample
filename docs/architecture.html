Figma design system sample — architecture

Three boxes, and only the middle one holds a key

A designer marks a frame ready for development. That status change is the only trigger, so drawing starts nothing and nobody has to remember a step. One small service reads the frame and opens an issue, and it is the only process anywhere holding a Figma token — the agent runs on GitHub with none at all, and sees what the issue carries and nothing more. The design pack governs every stage: it is the whole vocabulary the agent may use and the schema the checks judge against. A design asking for something the pack does not have is named as unmapped rather than guessed at, and a person approves before anything merges.

If the pack cannot build it

Nothing breaks and nobody guesses. The issue names the part it could not match, the agent is told not to invent it, and the pull request says what was left undone. Needing it often is a request to add it to the system, not a reason to work around it.
